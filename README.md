
# 📊 DATA_DASHBOARD

## Overview
This project is a **Data Analysis Dashboard** that integrates **Sales, Students, and Expenses datasets**.  
It provides interactive charts, KPIs, and insights to track performance, student outcomes, and financial management in one place.  
The goal is to demonstrate skills in **data cleaning, visualization, and reporting**.

---

## Features
- 📈 **Sales Analysis** – Revenue trends, profit margins, and regional comparisons  
- 🎓 **Students Analysis** – Enrollment stats, performance tracking, and demographics  
- 💰 **Expenses Analysis** – Category-wise spending, monthly/yearly trends, and budget insights  
- 🔍 Interactive filters and slicers for deeper exploration  

---

## Tech Stack
- **Power BI / Tableau** (for dashboard visualization)  
- **Python (Pandas, Matplotlib, Seaborn, Plotly)** (for data analysis & charts)  
- **GitHub** (for version control and project showcase)
